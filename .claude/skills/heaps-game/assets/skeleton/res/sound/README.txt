Sound effects: one file per name of the Sfx enum (src/Audio.hx), as .wav or .mp3 (.ogg only on
HashLink). ui_move.wav, ui_confirm.wav, ui_back.wav, pause.wav, step.wav, bump.wav, goal.wav.
Variants are picked at random: step.wav, step_2.wav, step_3.wav...
A missing file is silent: the game works before the sounds exist.
